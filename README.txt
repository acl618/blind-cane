
 盲杖悬空障碍物预警模块 

 一、项目简介
针对传统盲杖只能探测地面、无法探测头部高度悬空障碍物（如树枝、空调外机、门头）的痛点，本项目基于Arduino平台开发了一款低成本、可挂载的智能预警模块。通过超声波传感器采集环境信息，结合软件滤波算法与多模态触觉反馈，帮助视障人士提前感知危险。

 二、包含硬件
主控：Arduino UNO
感知：HC-SR04 超声波传感器
反馈：蜂鸣器 + 震动马达
供电：充电宝
其他：杜邦线

三、原理
1. 超声波传感器以15度仰角（向上倾斜）安装于盲杖前端，专门探测头部高度悬空区域。
2. Arduino循环触发超声波测距，获取前方障碍物距离。
3. 原始距离数据经过“滑动平均滤波”平滑处理，消除手部抖动带来的高频噪声。
4. 计算距离变化率，若突变超过30cm，判定为行人路过等动态干扰，跳过报警。
5. 根据距离远近，触发不同频率的蜂鸣器声与震动马达触觉反馈。

四、核心算法
 1. 滑动平均滤波（解决手抖误报）
创建长度为5的循环队列（数组），每次测距将最新数据入队，同时踢出最旧数据，计算均值。
代码：total = total - readings[readIndex]; readings[readIndex] = currentDistance; total = total + readings[readIndex]; readIndex = (readIndex + 1) % 5; averageDistance = total / 5;`
效果：滤波后测距数据波动范围由原始约 ±15cm压缩至 ±3cm 以内。

2. 动态变化率过滤（解决行人干扰）
实时计算当前距离与上一次距离的差值（变化率）。如果变化率绝对值大于设定阈值（如30cm），则判定为动态目标（如行人），直接跳过本次报警逻辑。
代码：if (abs(changeRate) > 30) { return; }`
效果：实测快速划过30次，成功过滤28次（过滤率93%）。

五、开发经历
在从零搭建实物的过程中，遇到了一些真实的问题

1：超声波数据剧烈乱跳
现象：盲杖敲击地面时，超声波测距数据在0cm到200cm之间跳跃。
解决：引入滑动平均滤波算法，对连续采样取均值，有效平滑了随机噪声。

 2：行人与真实障碍物无法区分
现象：路人快速走过时，系统误以为遇到悬空障碍物，疯狂报警。
解决：设计变化率过滤算法，剔除突变数据；并加装物理导向罩收窄探测角度。

3.距离过远时误报
现象：初版代码写分级预警时忽略了探测距离过远导致超声波返回时间长，错误预警。
解决：当距离过远，超声波返回时间长时代码自动把距离记为999cm，不再错误预警。
